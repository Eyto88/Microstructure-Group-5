# Crystal structure & strengthening — 17-4PH

Owner(s):

## Starting points (verify against sources and cite each one)

- **Composition (wt%):** Cr 15–17.5, Ni 3–5, Cu 3–5, Nb+Ta 0.15–0.45, C ≤ 0.07.
- **Phases:** austenite (FCC) at ~1040 °C → low-carbon lath martensite (BCC/BCT) on cooling.
  - The martensite start temperature (Ms) is only ~100–150 °C, so anything that lowers it leaves retained austenite.
  - Some δ-ferrite is possible.
- **Strengthening:**
  1. Martensite (dislocation substructure).
  2. **Cu-rich precipitates** from ageing — coherent BCC clusters at peak strength (H900), coarsening to incoherent FCC ε-Cu when overaged (H1150).
  3. NbC (ties up C, pins grain boundaries).
- **Contrast with 316L:** stable FCC austenite; in AM it is strengthened by fine cells, dislocations and twinning; it can't be precipitation-hardened.
