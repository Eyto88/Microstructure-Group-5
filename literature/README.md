# Literature

## Files

- **`reading_list.xlsx`**
  - The **17-4PH papers** tab lists every paper behind our dataset, with title, DOI link, rows contributed, topic and priority (*Core / High / Medium / Low / Check*).
  - The **Full list annotated** tab rates all 166 papers from the course paper list. It contains no 17-4PH, but it is useful for the **316L** comparison and for general LPBF process physics.
- **`references.md`** — the reference list for the slides. Add anything you cite.
- **`notes/`** — one file per lit-review topic. Write in your own words and put the reference next to each claim.
